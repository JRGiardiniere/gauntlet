Gauntlet v2 is one CLI on an embedded OpenCode Host. Claude and OpenAI Seats
run through the same agent loop, tools and permission fence, and one Recipe
can mix them.

## Breaking changes

- **The Claude Code Mod (`/gauntlet`) is retired.** Claude Seats run from the
  CLI. Remove the Mod with
  `claude plugin uninstall gauntlet && claude plugin marketplace remove gauntlet`.
- **Pi is gone.** OpenAI sign-in is `gauntlet login` (ChatGPT), or
  `OPENAI_API_KEY` in the environment. Your Pi login is not used.
- **Claude Seats need `claude`** installed and logged in. Set
  `OPENCODE_CLAUDE_PATH` to the real executable if it isn't on PATH or is a
  shim such as mise's.
- **`--spec <file>` is the only Specification Source.** Linear and GitHub
  closing-issue lookup and `--github-spec` are removed; fetch issues yourself
  and pass them with `--spec`.
- **Removed:** the HTML Dossier page, `page-data.json`, and the `page` and
  `brief` commands. `dossier.md` and the digest remain.
- **The digest is shorter:** findings grouped by Review Priority with P3s
  counted, coverage gaps, and tokens and cache hit rate per Stage instead of
  dollars.
- **v1 Runs:** v2 commands support only Runs made by v2, so `deliver` of a v1
  Run may fail. Deliver pending v1 Runs before upgrading.

## New

- `claude-low`, `claude-medium` and `claude-high` Recipes;
  `gauntlet config init` adds them to an existing configuration without
  touching your recipes.
- Agents get at most read-only `read`, `grep` and `glob`, fenced to a frozen
  snapshot: `.git`, `.env*` and paths outside it are refused, and the
  reviewed repository's own agent configuration never loads.
- Lockfiles are kept out of the inlined diff and related files.

## Upgrading

`gauntlet upgrade`. Recipes, settings, lenses and runs in `~/.gauntlet` stay.
Then sign in (`gauntlet login`, or `OPENAI_API_KEY`) and run
`gauntlet upgrade` once more: it moves any recipe Seat still on a legacy
provider such as `openai-codex/` to the newest model the Host lists.
`gauntlet config init` adds the Claude recipes.
