# Dossier page

Scope: the HTML reading of one Gauntlet Run's Dossier, written beside dossier.md. Mode: Read (triage). Reader: John right after a run. Job: decide fix / argue / skip, mark reviewed, hand a finding to the agent. Constraints: one offline HTML file; two views (default deterministic; agent-authored Judgment view) from one typed-block renderer; Gauntlet priority inks.

## Direction contract

THESIS: Every finding already stood before a tribunal; the page is the case file it left behind. Refuses the dashboard-plus-card-feed and the GitHub diff clone.

OWN-WORLD: A kraft folder (tab spine, ruled index sheet) holding bond-paper exhibit sheets; condensed form-header grotesk for fields, tabs and exhibit tags; workhorse text face for prose; mono only for code. One ruled neutral ramp; colour only as adjudication ink: rectangular double-ruled stamps (CONFIRMED / KEPT / PLAUSIBLE) in P1 #e5484d, P2 #ff8700, P3 #e0b000, stamp size on a fixed three-step ramp by priority. Exhibit tags (E-01) pin to the cited code line by a leader rule. Reviewed = an initialled check stamp; a tape flag marks where you stopped; refuted and dropped hang in a Set-aside sleeve at the back.

STORY: The reader opens the file, reads the index sheet (case, subject, tribunal, filed, cost), sees the spine's P-tabs, walks exhibits in priority order with claim and evidence side by side, stamps each reviewed, and leaves a flag; Judgment-path exhibits offer the agent-authored brief.

FIRST VIEWPORT: Left, a sticky kraft tab spine (P1 P2 P3 / Unresolved / Set aside, counts, exhibit index with check and flag marks). Right, the index sheet as ruled form fields across the top third; below it Exhibit E-01 begins: tag, location, stamp at top-right, claim column left, evidence column right with the cited line pinned.

FORM: The Case File, candidate 7 of my ordered list (the literal reading), seed 669aabda. Signature interaction: pressing x stamps the open exhibit reviewed (stamp lands with a short ink-press motion) and moves the flag; j/k walk exhibits and the spine follows.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
